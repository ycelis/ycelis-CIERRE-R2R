# Carpeta de datos

## ¿Qué va aquí?

Sube tu archivo Excel con el nombre exacto:

```
cierre.xlsx
```

## Columnas requeridas

| Columna | Descripción |
|---|---|
| `Name` | Nombre de la actividad |
| `Dia` | Día del cierre (número) |
| `Operación` | MEXICO o SCAC |
| `Estatus Cierre` | COMPLETED / IN PROCESS / NOT STARTED / NOT APPLICABLE |
| `Responsable` | Nombre del responsable |
| `Areas` | Nombre del área |
| `PAISES` | País(es) separados por coma |
| `Estatus Entregable` | Cierre / Postcierre (opcional) |
| `Comentarios` | Comentario libre (opcional) |

## Cómo actualizar el dashboard

1. Actualiza tu archivo Excel con los datos del mes.
2. Renómbralo a `cierre.xlsx`.
3. En GitHub, ve a esta carpeta `data/`.
4. Haz clic en **Add file → Upload files**.
5. Arrastra tu `cierre.xlsx` y haz commit.
6. En 1-2 minutos el dashboard se actualiza automáticamente en GitHub Pages.

## Descarga la plantilla

Abre el dashboard en GitHub Pages y haz clic en **"Descargar Plantilla"**
para obtener un Excel con el formato correcto.
